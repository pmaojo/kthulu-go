# Contributing to Kthulu Go

Thank you for your interest in contributing to Kthulu Go! We welcome contributions from the community.

## Getting Started

1.  Fork the repository.
2.  Clone your fork: `git clone https://github.com/your-username/kthulu-go.git`
3.  Create a branch: `git checkout -b my-feature-branch`

## Development

-   **Go Version**: Ensure you have Go 1.24+ installed.
-   **Dependencies**: Run `go mod tidy` to install dependencies.
-   **Testing**: Run `go test ./...` to run tests.

## Submitting Changes

1.  Push your changes to your fork.
2.  Open a Pull Request against the `main` branch.
3.  Describe your changes clearly.

## Code Style

-   Follow standard Go conventions (Effective Go).
-   Run `go fmt ./...` before committing.

We look forward to your contributions!
