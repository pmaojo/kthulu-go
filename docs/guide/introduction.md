# Welcome to Kthulu

Kthulu is a suite of tools designed to make Go development fast, fun, and robust.

## Key Features

- **AI Scaffolding**: Generate entire projects from natural language.
- **Self-Healing Dev Server**: Real-time error diagnosis and fixing.
- **Architecture Diagrams**: Auto-generate Mermaid diagrams from code.
- **Marketplace**: Discover and inject modules with one command.
