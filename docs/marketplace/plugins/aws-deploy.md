# AWS Deployment Plugin

Scale your Kthulu backend to the cloud effortlessly.

## Capabilities

- **Lambda**: Serverless compute.
- **RDS**: Managed PostgreSQL.
- **S3**: Static asset storage.
- **CloudFront**: Global CDN.

## Usage

```bash
kthulu add plugin aws-deploy
```
