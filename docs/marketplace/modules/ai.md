# AI Module

The AI module brings agentic coding capabilities directly to your Kthulu Go application.

## Features

- **Code Generation**: Automatically scaffold components, modules, and boilerplate.
- **Self-Healing**: Detect and fix issues in your development environment.
- **Project Scaffolding**: Create entire project structures from simple descriptions.
- **BDD Integration**: Generate Gherkin features and step definitions.

## Installation

```bash
kthulu add module ai
```

## Usage

Use the `kthulu ai` command to interact with the AI assistant.
