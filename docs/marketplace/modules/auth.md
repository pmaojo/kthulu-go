# Authentication Module

Add secure authentication to any Kthulu project in seconds.

## Features

- JWT Token management.
- Refresh tokens support.
- Middleware for RBAC.
- Ready-to-use login/register routes.

## Usage

```bash
kthulu add module auth
```
