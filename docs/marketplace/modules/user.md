# User Module

Complete user management system with profile support, password management, and account settings.

## Features

- **Profile Management**: CRUD operations for user profiles.
- **Account Settings**: Manage email, passwords, and preferences.
- **Avatar Support**: Built-in support for user avatars.
- **Role Integration**: Seamlessly works with the Auth module for role-based access.

## Installation

```bash
kthulu add module user
```
