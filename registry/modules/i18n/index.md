# I18n

I18nModule provides internationalization functionality. Supports JSON/YAML translation files and pluralization.

## Features


- Auto-configured Fx Module
- Clean Architecture structure



## Configuration

The module is configured via environment variables:

| Variable | Description |
|----------|-------------|
| - | No environment variables detected |


## Installation

Add this module to your project:

```bash
kthulu add module i18n
```

## Components

This module provides the following components to the application:

- **Backend**: Go module wired with Uber Fx.
